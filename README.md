# 茶饮门店竞争格局与选址分析（Yelp 开放数据）

> 真实商户数据 · Python (pandas / numpy / scipy / matplotlib) · 含自我推翻与稳健性检验

## 一、业务问题

新开一家茶饮门店，最贵的决策是选址。本项目用真实商户数据回答：

1. **市场格局**：茶饮门店集中在哪些市场？竞争密度呈什么分布？
2. **竞争效应**：周边竞品越多生意越差吗？——真实数据的答案与直觉相反，但需要检验
3. **选址决策**：哪些市场"需求已验证、供给未饱和"？成熟市场内部如何下沉选街区？

## 二、数据说明

- **数据来源**：[Yelp Open Dataset](https://www.yelp.com/dataset)（官方开放数据集），商户子集 **150,346 家**
- **覆盖范围（重要）**：该数据集对应 Yelp 的 **8 个都市圈、15 个州/省**（含加拿大 AB），因此结论仅适用于"Yelp 覆盖市场"，不能推广为全北美或全国结论
- **提取口径**：categories 含 `Bubble Tea` / `Coffee & Tea` / `Tea Rooms` → **7,069 家茶饮门店**，其中奶茶店 **477 家**（已核验：Boba / Milk Tea 等拼写变体无遗漏）
- **字段**：business_id、城市、州、邮编、类别、经纬度、星级评分、累计评论数
- **关键特征构建**：原始数据**不含"周边竞品数量"**。用经纬度 + Haversine 球面距离，计算每家奶茶店 **0.5 / 1 / 2 / 3km 四档半径**内的同类门店数（同州掩码避免跨界误计，已核验漏计 0 家）
- **需求代理变量**：Yelp 无销量数据，用**累计评论数**作为历史需求代理；局限与检验见第六节

## 三、核心发现

- **Q1 市场集中**：茶饮门店前 5 城占总量 34%；费城以 956 家茶饮店（含 97 家奶茶店）为最大单一市场。⚠️ 城市字段由用户填写，同一都市圈可能被拆成多城（如 Philadelphia 与 Cherry Hill）
- **Q2 两极分化**：38% 的奶茶店 1km 内零竞品，30% 与 3 家以上贴身竞争
- **Q3 密度与需求（含自我推翻）**：初版得到"竞品密度与热度正相关 r=0.19，存在集聚效应"；**`03_threshold_probe.py` 推翻了它**——高密度样本全部来自费城唐人街 19107 一个街区（23 家店，均评论 186 vs 费城其他 56），属伪重复（pseudo-replication）；剔除该街区后 r 降至 0.016、分组差异不显著（p=0.76）
- **Q4 评分梯度**：评分随密度单调下降（4.18 → 3.88），Kruskal-Wallis **p=0.0001 显著**；剔除唐人街簇后 **p=0.0017 仍显著**（4.18 → 3.86）——与 Q3 热度结论不同，评分分化不是伪重复造成的；但"竞争淘汰"与"评分分化"两种机制无法区分
- **Q5 蓝海市场（口径已修正）**：需求强度（该市奶茶店中位评论）× 供给稀缺度（1 − 奶茶渗透率）。入选 **11 个市场**（奶茶店≥5、茶饮店≥50），前五为 **Reno、Indianapolis、New Orleans、Tucson、Nashville**；其中 New Orleans 奶茶渗透率仅 1.8%、存量店中位评论 91 条
- **Q6 街区粒度**：费城 19107 热度最高（均 186 条评论、23 家店）——城市内部差异巨大，选址需下沉到街区。⚠️ 该街区与 Q8 的伪重复簇同源，仅作示例、不作独立证据
- **Q7 决策建议**：优先 Q5 蓝海市场 → 进入经需求验证的成熟商圈 → 街区粒度筛铺位；**不应把"竞品数量"当择址指标**（Q8）；未含成本数据，回报结论留白
- **Q8 阈值检验**：不存在可推广的"竞品数阈值"——细粒度曲线非单调（0家 78 → 1家 63 → 2家 85 → 3-5家 73-76 → 7家 43 → 8家 112 → 22家 186）。**竞品数量是优质商圈的"症状"而非"病因"**
- **Q9 稳健性（`04_robustness.py`）**：
  - **半径敏感性**：0.5 / 1 / 2km 三档下，剔除唐人街簇后 r = 0.046 / 0.016 / −0.028，p 均 > 0.05 → "密度不提升需求"对半径选择稳健
  - **排序稳定性**：bootstrap 1000 次后，Reno（87%）、New Orleans（82%）稳定进入前 3 → 蓝海排序可对外表述为"候选池排名"

## 六、局限与改进方向

1. **代理变量偏差**：累计评论数 ≠ 销量，且缺开店日期，老店天然占优；改进：拉取评论时间戳算近 12 个月增速，或用开业年份控制
2. **幸存者偏差**：Yelp 只收录存续门店，无法回答"哪些位置更危险"
3. **覆盖范围**：仅 8 个都市圈 / 15 州省，结论不可外推至全美；蓝海候选池仅 11 个市场，样本小
4. **市场规模用茶饮店数代理**（无人口数据）：小球市仍可能被高估，改进：接入人口或租金数据
5. **空间伪重复**：同商圈门店不是独立观测——已在 Q3/Q8/Q9 处理，但其他分组分析仍可能残留此问题
6. **未控制混杂**：无租金/成本/品牌连锁信息，只能谈需求侧，不能谈盈利；改进：商圈固定效应 + 多元回归

## 七、简历版本（3 行）

- 基于 Yelp 开放数据（15 万真实商户）构建茶饮选址分析：提取 7,069 家门店，用 Haversine 公式自建 0.5–3km 四档竞品密度特征，完成 477 家奶茶店的密度—需求分析
- 初版发现"竞品密度与热度正相关（r=0.19）"，经伪重复检验发现结论由费城唐人街单一街区驱动（剔除后 r=0.02、p=0.76），主动推翻并修正为"竞品数量是优质商圈的症状而非病因"，并用三档半径敏感性验证结论稳健
- 以"需求强度×供给稀缺度"构建蓝海指数（口径统一、bootstrap 验证排序稳定），输出 Reno / New Orleans 等候选市场与街区级选址建议，完整披露代理变量、幸存者偏差与覆盖范围三类局限
